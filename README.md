# 📈 K線操盤挑戰 ChartGame

**🎮 線上版:https://jackychan122.github.io/chartgame/**

重現 [chartgame.com](https://www.cmoney.tw/notes/note-detail.aspx?nid=8700) 的K線模擬投資遊戲:
系統隨機抽出一檔**真實美股**的過去走勢(名稱與日期全部隱藏),你只有圖表與技術指標。
本金 $10,000 全額進出,測試你的技術分析能不能打敗「買進持有」。

## 玩法

| 操作 | 說明 |
|------|------|
| 🟢 **買進 (B)** | 全額買進,在下一根K棒的**開盤價**成交 |
| 🔴 **賣出 (S)** | 全部賣出,同樣在下一根開盤價成交 |
| ⏩ **快轉 (T / 空白鍵 / →)** | 不出手,時間前進;`1` `2` `3` 切換 ×1 / ×5 / ×20,長按快轉連續播放 |
| ▶ **自動 (A)** | 自動播放 / 暫停 |
| **換一檔** | 放棄這一局、換一張圖(不計入戰績) |

- 對手是「買進持有」:在你出發那一根的開盤價全額買進,抱到最後一根收盤。
- 下方的「資產對比」窗格即時畫出你和買進持有的資產曲線;圖上的連線是每個買賣回合的損益。
- 最後一根自動以收盤價清倉結算,並揭曉股票與日期。報酬只算價差,不含股息。
- 結算後可以**分享挑戰連結**,讓朋友玩同一張圖;「重玩這張圖」屬於練習,不計入戰績。
- 期間:3個月 / 6個月 / 1年(日K)、2年 / 5年(週K)、隨機。

## 標的與資料

- **200 檔美股**,其中 189 檔是 S&P 500 成分股(另外 11 檔是第一版已有的非成分股)。
  新增的 130 檔是名單中還沒收錄、指數權重最大的成分股(2026-11 的名單)。
- 每檔 **20 年日K**(2006–2026),來源為 Yahoo Finance,股價已按拆股調整。
- 每一局的K棒都落在**單一段連續走勢**之內。建置時會在以下位置切開數列,
  避免分拆、特別股息、ticker 重用或資料缺漏造成假的跳空:
  時間缺口超過 20 日、單日升跌達 60%、分派達股價 8%、拆股日價格異常、連續 3 根零成交。
- 上市不夠久的股票只會出現在歷史長度足夠的期間(例:5 年局有 174 檔可選)。

## 在本機執行

在專案資料夾啟動本地伺服器:

```
py -m http.server 8123
```

打開 http://127.0.0.1:8123 。程式沒有建置步驟,也不需要 Node。

## 測試

用瀏覽器打開 `tests/logic.html`(例如 http://127.0.0.1:8123/tests/logic.html ),
會直接執行 32 項測試並顯示結果:遊戲規則、指標、資料層、儲存層,
以及頁面與程式的一致性(id 不重複、程式取用的元素存在、每顆按鈕都接上處理程式、圖示引用存在)。

測試的儲存層已換成記憶體,不會讀寫瀏覽器真正的戰績與偏好
(測試本身也會驗證這一點)。

## 檔案結構

```
index.html            主頁面
css/style.css         樣式
js/game.js            遊戲規則(純邏輯,不碰 DOM)
js/data.js            股票資料載入、週K 聚合、連續區段、選股
js/indicators.js      技術指標計算(全部為因果計算)
js/chart.js           圖表:K線、指標窗格、資產對比、買賣連線
js/store.js           localStorage:指標偏好、戰績
js/app.js             介面與流程
lib/                  Lightweight Charts v5(本地)
data/                 200 檔股票資料(每檔一個 .js)+ index.js
tools/download_data.py  資料建置腳本
tools/universe.py       200 檔的清單與中文名
tests/logic.html      邏輯測試
```

## 重建資料

```
py tools/download_data.py                 # 全部 200 檔
py tools/download_data.py --only AAPL,MSFT
```

需要 Python 3 標準庫與網路連線。腳本會檢查拆股調整、列出每檔的區段與異常,結束時列在 `notes:` 之後。

`tools/sp500_snapshot.json`、`tools/sp500_weights.json` 是 2026-11 的成分股名單快照
(來源:Wikipedia、slickcharts),由 `tools/parse_sp500.py`、`tools/parse_slick.py` 產生,只在建置時使用。
`tools/make_og_image.py` 產生分享預覽圖 `og-image.png`(需要 Pillow)。

> 資料僅供遊戲練習,非投資建議。
