# 📈 K線操盤挑戰 ChartGame

**🎮 線上版:https://jackychan122.github.io/chartgame/**

重現 [chartgame.com](https://www.cmoney.tw/notes/note-detail.aspx?nid=8700) 的K線模擬投資遊戲:
系統隨機抽出一檔**真實美股**的過去走勢(隱藏股票名稱與日期),你只有圖表與技術指標,
本金 $10,000 全額進出,測試你的技術分析能否打敗「買進持有」。

## 玩法

| 操作 | 說明 |
|------|------|
| 🟢 **買進 (B)** | 全額買進,於下一根K棒**開盤價**成交 |
| 🔴 **賣出 (S)** | 全部賣出,於下一根K棒開盤價成交 |
| ⏩ **快轉 (T / 空白鍵)** | 不出手,前進一根K棒;可切 ×1/×5/×20、長按連播、▶ 自動播放 |

- 對手是「買進持有」:從你的第一根開盤全額買進、抱到最後收盤。
- 最後一根自動以收盤價清倉結算,並揭曉股票與日期。
- 右側工具箱:MA20/50/200 均線、布林通道、成交量、MACD、RSI。
- 期間選擇:3個月/6個月/1年(日K)、2年/5年(週K)。
- 戰績自動存在瀏覽器 localStorage。

## 執行

**方式一(已實測)**:在專案資料夾啟動本地伺服器
```
py -m http.server 8123
```
打開 http://127.0.0.1:8123

**方式二(未實測)**:直接雙擊 `index.html`。程式不使用 fetch,資料全以 `<script>` 標籤載入,
理論上可在 `file://` 下運作,但尚未實際驗證;若圖表或股票資料載不出來,請改用方式一。
